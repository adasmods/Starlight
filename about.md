# Starlight

Kosmiczne mod menu do Geometry Dash (osobiste użycie).

- **Tab** otwiera/zamyka menu (można zmienić w panelu *Interface*)
- Animowane panele, gwiezdne tło, fioletowo-czarny motyw
- Hacki: noclip, speedhack, FPS bypass, safe mode, respawn delay, hitboxy...
- Wizuale: orby lecące za graczem, aura gracza, kosmiczny gradientowy trail, skyboxy (noc, zachód słońca, mgławica, krwawy księżyc)
- Labelki: cheat indicator, FPS, CPS, noclip accuracy, próby, procent, czas, zegar
  - przeciąganie myszką w edytorze (*Labels → Edit Positions*), każdy font z GD + motyw **Starlight Theme**
- Keybindy: skok pod dowolnym klawiszem (3 sloty), skok P2, lewo/prawo w platformerze
- Nick changer (tylko wizualny)
